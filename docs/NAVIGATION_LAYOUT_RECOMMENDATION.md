# Navigation Layout Recommendation

This pass does not move or redesign the global navigation.

## Recommendation

A left-side collapsible navigation rail would likely fit YucaTanaTrades better long term because the top navigation is becoming crowded as more terminal modules come online.

## Suggested Future Structure

Left sidebar:

- Dashboard
- Meridian
- News
- Options Flow
- Stocks
- Crypto
- AIheatmap
- Crypto Hunter
- Portfolio
- Charts
- Settings

Top bar:

- Logo
- Clock
- Profile/account settings
- Sign out
- Quick ticker/search row

## Implementation Note

Do not implement the sidebar in this UI refinement pass. The current global navigation placement should remain unchanged until a dedicated layout phase is requested.
